# Clasificador de Tweets / Reviews

Proyecto de clasificación de texto listo para Google Colab. Incluye EDA, TF-IDF, modelos y SHAP.

## Abrir en Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/DanyPreisz/tweets-reviews/blob/main/tweets_reviews_colab.ipynb)

## Contenido

- EDA (distribución, longitud de textos)
- TF-IDF vectorizer
- Modelos: Logistic Regression, Random Forest
- Matriz de confusión + classification report
- Palabras más importantes (coeficientes)
- **SHAP** (ejemplo)
- Conclusiones

Dataset: SMS Spam Collection (proxy tweets/reviews)

Rango esperado: Accuracy ~0.97–0.99 | ROC-AUC ~0.98–0.99
